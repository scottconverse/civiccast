## Owner decision

The publisher normally needs a physical-host consumer receipt (a recorded install on a test PC). The owner (Scott Converse) ordered the publish on 2026-11-15 without that receipt. The publisher ran with only that one check replaced by an installer hash check. Gate A was not run.

The station evidence for this build is the 28-hour, five-PC soak: [SOAK-REPORT.md](../evidence/rc6-soak-2026-11-15/SOAK-REPORT.md). All five stations ran the same installer hash shown above.

The kit's `station` folder also held `core-notice.txt` and `native-station-bundle-report.json`. They are build notes, not station packs, and rc.5 did not ship them, so they were left out of the station-models bundle.

## What changed since rc.6

**The on-air clock shows the station's time (#347)**

Before: the CG board clock showed UTC, so a Mountain-time station read 04:04 at 21:04. Now: a named station time zone wins; the `local` default, or an unknown zone name, uses the station PC's own time zone. It never falls back to UTC.

**A power cut no longer breaks caption scans**

Before: the caption program boundary file was written in place, so a station that lost power came back with an empty file and a control-plane error on every caption scan. Now: the file is written to a temp copy, flushed to disk and then put in place, and an empty, broken or non-text file reads as "no boundary" with one warning per file instead of an error on every scan.

**Live captions are on by default**

Before: a new station had live captions off until an operator turned them on. Now: a new station has them on. A station that saved "off" under an older build is turned on once at upgrade; an operator who turns them off after that keeps them off. `CIVICCAST_CAPTION_TAP=off` still turns them off. Saving the switch shows when it takes effect and offers an "Apply captions now" button per channel, which restarts only that channel's playout, never the service.

**The staff token commands work on an installed station**

Before: `civiccast token issue`, `list`, `revoke` and `rotate` needed `DATABASE_URL` set by hand in the window. Now: the commands read the database address from the installed service's own setting and never print it; a window that is not elevated is told to open PowerShell as administrator; and `--out` writes a new token to a new file whose rights allow only the writer, SYSTEM and Administrators. An existing file is refused before any token is issued.

**A stopped service stops its child programs**

Before: the stop overran 15 s and Windows force-closed `control_plane` and `ollama`, because CTRL_BREAK never reached children without a shared console. Now: the sender joins the child's console for the one call, sends the break, and logs a warning if it still cannot be delivered.

**`station-state.json` keeps its own file rights**

Before: every save rebuilt the rights around the program doing the write, so a save from an admin tool could cut the service's access. Now: a protected, narrow rights list is read first and put on the empty temp file before any byte is written; a new, inherited or broad one still gets the strict default, and if the kept rights would block the save it falls back to that default instead of failing.

**A content reload that finds nothing due no longer strands a channel**

Before: on R7, schedule commits a few minutes before the first program threw away the reload already armed for that program and pinned the channel in TRANSITIONING until the stall watchdog (about 1650 s). Now: the armed reload is kept, an earlier pin is dropped and its prior state restored, and a late settlement for a discarded reload puts the reload back at once.

**The health check stays fast and accurate**

- `/health` reuses the app's pooled connection instead of opening a new database connection for each schema check, so it no longer takes 10-14 s on a low-memory PC.
- A channel showing its slate no longer makes `/health` say `degraded`: a caption worker that is alive and idle while its slate is on air counts as having nothing to caption. A programme whose sound stops still reads unknown, and a real caption failure still reads degraded.

**A programme change is bounded**

Before: one segment's preparation took 910.6 s and its failure surfaced 8 minutes after the outgoing programme ended, leaving the public channel on its slate for 13 minutes (Dell, rc.6). Now: a reload's preparation is abandoned with a clear log line once the outgoing programme's end plus 60 s has passed, or after two preparation timeouts plus 60 s for a hand-started reload, and the existing retry runs at once.
